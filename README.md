# Keep the Lights On

A game for [Squeekchain](https://squeekchain.com): Squeektoshi's wheel powers a string of bulbs. Every 10 minutes he
keeps running, the next bulb lights up. Bet test SQK on a bulb; when he falls asleep, the lit bulbs share the pot.
Settled on Sepolia straight from SqueekCore's rounds, with no server and no admin.

Work in progress. The contract, the website and their tests will land here.
